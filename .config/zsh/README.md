# Personal Zsh files

`completions/_xsel` and `themes/robbyrussell.zsh-theme` preserve the personal
files previously held inside the nested `.oh-my-zsh` checkout.

`.zshrc` loads this completion directory before Oh My Zsh initializes.
The saved theme is available as a reference; the active theme remains
Powerlevel10k. Keep future personal changes here rather than editing upstream
Oh My Zsh files.
